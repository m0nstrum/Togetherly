# Наш дом: общий питомец

Утверждено владельцем 26.10.2026. Визуальное направление: тёплый рисованный
миниатюрный дом, дерево, кремовый, шалфейный и терракотовый цвета. Собственные
рисунки, загруженные картинки, галерея и существующие виджеты сохраняются.

## Правила продукта

- Один дом на связь, общий для участников. Для пары — семейные обращения;
  для друзей и других связей — имена. Каждый выбирает своё обращение сам:
  мама, папа, имя или произвольное прозвище. Роли по полу не угадываем.
- Кормление, мытьё, игра, ласка: короткие добровольные занятия с реакциями.
  Нет голода по таймеру, смерти, болезней, штрафов, обязательных заходов,
  требовательных уведомлений или оплачиваемого восстановления.
- Базовый дом сразу. Мебель за игровые очки уюта: стартовый запас,
  постоянные достижения по уходу и обычная совместная активность. Без
  ежедневной нормы; покупки общие, повторно не оплачиваются. Реальных денег нет.
- Пользовательский рисунок/фото остаётся исходным изображением. Оживляем
  трансформациями, эффектами, облачком; не требуем новых кадров от владельца.
- Реплики короткие, тёплые, с юмором, привязаны к событию, без упрёков;
  учитывают обращения/имена без склонения. Облачко исчезает и не мешает.
- Фон, мебель, предметы ухода и эмоуты — отдельные ресурсы; анимации
  учитывают настройки уменьшения движения, действия доступны TalkBack.
- Обстановка, обращения и события ухода зашифрованы ключом связи. Общие
  изменения сохраняются с проверкой версии и повтором при конфликте.

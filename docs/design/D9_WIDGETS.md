# D9. Вкладка «Виджеты»: разделы, настройки, структура

Статус: дизайн-док, ждёт ОК владельца. Код — отдельным PR после ОК, вместе
с A12-1 (разрезка `lib/screens/widget_screen.dart`, часть 1 — PR #28).

## Проблема

Жалоба из бэклога: вкладка «Виджеты» — длинная лента, где непонятно, что
уже стоит на рабочем столе, что можно поставить и где что настраивается.
Настроек мало, и они лежат не там, где их ищут.

## Как сейчас

Экран — одна прокрутка сверху вниз:

1. шапка «Виджеты» с кнопкой сброса;
2. полоса «на iOS 15–16 виджетов нет» (только там);
3. баннер открыток;
4. каталог «Виджеты рабочего стола» — пять сворачиваемых разделов
   (`WidgetPanels`, раскрытие помнится в prefs).

| Раздел | Карточки | С настройками внутри |
|---|---|---|
| Вы вдвоём | Парный виджет, Вместе⁺, Скучаю⁺, Где мы, Статистика, Маскот | только Парный виджет |
| Дни и таймеры | Счётчик дней, плитки «Серия» и «Таймер», Лепестковый таймер, Обратный отсчёт⁺, Кольцо года⁺, Сетка года⁺ | Счётчик дней («наши фото»), Лепестковый (выбор таймера); у плитки таймера — лист выбора по тапу |
| Фотографии | Моё фото, Фото партнёра, Фото-сетка, Рисунок на столе | первые три |
| Настроение | Настроение, Плитки настроения⁺, Экран блокировки | Экран блокировки (вкл/выкл) |
| Заметки | Заметка⁺, Заметка-листок⁺ | — |

⁺ — платные (замок у некупивших; на iPhone без Togetherly+ скрыты, 3.1.1).

Карточка — превью, выбор размера (2×2 · 4×2 · 4×4, где есть), кнопка
«Поставить», у части — раскрываемый блок настроек.

Что мешает:

- **Не видно, что уже стоит.** Каталог одинаков до и после установки.
  На Android это знает система (`HomeWidget.getInstalledWidgets` — им уже
  пользуется подтверждение установки), но на экран это не выводится.
- **Настройки спрятаны в карточки каталога.** Общие переключатели
  (автосохранение фото, сообщений и музыки в «Воспоминания», настроение
  в календарь) живут внутри раскрытого «Парного виджета», хотя к нему
  отношения почти не имеют.
- **Настройки разношёрстные.** У одних карточек они есть, у других
  (Где мы, Статистика, Маскот, Вместе, Скучаю, заметки, годовые) — нет
  ничего, даже там, где выбор напрашивается (какую дату считать, что
  показывать).
- **Длина.** 21 карточка; на телефоне раздел «Вы вдвоём» один занимает
  несколько экранов.

## Варианты

### А. Оставить каталог, добавить сверху «На рабочем столе»

Над каталогом — полоса уже поставленных виджетов (Android: по
`getInstalledWidgets`; iOS — см. вопрос 7, пока не проверено — полоса
скрыта). Тап — лист настроек
этого виджета. Общие переключатели — в отдельную карточку «Общие
настройки» в конце.

\+ малая переделка, ничего не теряется; − экран станет ещё длиннее.

### Б. Две вкладки: «Мои виджеты» и «Добавить»

Сверху сегменты.

- **Мои виджеты** — поставленные виджеты карточками с их настройками,
  внизу «Общие настройки». Пусто — подсказка и кнопка «Добавить виджет».
- **Добавить** — нынешний каталог по разделам, но карточка короче:
  превью, размер, «Поставить». Настройки — не в каталоге, а в «Моих
  виджетах» после установки (до установки настраивать нечего).

\+ понятный путь «выбрал → поставил → настроил»; каталог короче;
− больше переделки; на iOS «Мои виджеты» могут оказаться пустыми, если
список поставленных не удастся получить (вопрос 7).

### В. Один каталог, у каждой карточки — шестерёнка

Настройки каждой карточки — в листе по шестерёнке, разделы как сейчас.

\+ единообразно; − всё ещё не видно, что стоит, и не решает длину.

## Рекомендация

**Б**, с запасным путём для iOS: если список поставленных на iPhone
получить нельзя, «Мои виджеты» там показывают все виджеты, у которых есть
настройки, с пометкой «если он стоит у вас на экране», а у карточек
каталога остаётся кнопка настроек. Реализацию вести после второй части
A12-1: карточки уже будут отдельными виджетами, и перестановка не
утонет в файле на 7 тысяч строк.

```
┌──────────────────────────────────────┐
│ Виджеты                         ⟲    │
│ [ Мои виджеты ]  [ Добавить ]        │
├──────────────────────────────────────┤
│ НА РАБОЧЕМ СТОЛЕ · 3                 │
│ ┌──────────┐ Парный 4×2              │
│ │ превью   │ фото, статус, музыка  › │
│ └──────────┘                         │
│ ┌──────────┐ Счётчик дней 2×2        │
│ │ превью   │ с 14.02 · наши фото   › │
│ └──────────┘                         │
│ ┌──────────┐ Фото партнёра 2×2       │
│ │ превью   │ каждые 30 мин         › │
│ └──────────┘                         │
│                                      │
│ ОБЩИЕ НАСТРОЙКИ                      │
│ Фото → «Воспоминания»          [●]   │
│ Сообщения → «Воспоминания»     [●]   │
│ Музыка → «Воспоминания»        [ ]   │
│ Настроение → календарь         [●]   │

```

Лист настроек виджета (по ›): превью сверху, ниже — настройки этого
виджета, внизу «Как убрать с рабочего стола» (убрать программно Android
не даёт — только подсказка).

```
┌──────────────────────────────────────┐
│ Добавить                             │
│ Вы вдвоём   Дни   Фото   Настроение  │  ← чипы-фильтры вместо
│                                      │    сворачиваемых разделов
│ ┌──────────────┐ ┌──────────────┐    │
│ │ Парный       │ │ Где мы       │    │  ← сетка по две карточки:
│ │ 2×2 4×2      │ │ 4×2 4×4      │    │    превью, размеры,
│ │ [Поставить]  │ │ [Поставить]  │    │    «Поставить»
│ └──────────────┘ └──────────────┘    │
└──────────────────────────────────────┘
```

## Какие настройки добавить

Только то, что виджет может показать без новой нативной работы, или с
малой. Остальное — вопросом владельцу.

| Виджет | Сейчас | Предлагается |
|---|---|---|
| Все | — | тема: как в приложении (сейчас всегда так, `WidgetThemeSync`) / светлая / тёмная |
| Счётчик дней, Вместе | наши фото (счётчик) | какую дату считать: начало отношений / свой таймер (как у лепесткового) |
| Где мы | — | показывать расстояние / только карту |
| Статистика | — | какие два числа показывать (воспоминания, рисунки, «скучаю», дни) |
| Маскот | — | какого маскота показывать, если их несколько |
| Скучаю | — | показывать оба счёта / только партнёра |
| Обратный отсчёт | ближайшее событие | выбрать событие вручную |
| Заметки | — | — (содержимое правится в самой заметке) |

## Что не меняется

- набор виджетов, их нативные разметки и провайдеры;
- платность и правило 3.1.1 для iPhone;
- запоминание выбора: раскрытие и размеры — `WidgetCatalogPanels`
  (prefs), новые настройки виджетов — туда же, где сейчас лежат
  настройки фото-виджетов (`HomeWidgetService`).

## Порядок работ после ОК

1. A12-1, часть 2: превью и карточки — отдельными виджетами (без
   изменения поведения).
2. Вкладки «Мои виджеты» / «Добавить», перенос общих настроек.
3. Список поставленных (Android) и запасной путь для iOS.
4. Новые настройки — по строке таблицы на PR, каждая с тестом.

## Вопросы владельцу

1. Вариант Б (две вкладки) или А (полоса «На рабочем столе» над
   нынешним каталогом)?
2. Чипы-фильтры вместо сворачиваемых разделов в «Добавить» — да?
   (Тогда помнить надо выбранный чип, а не набор раскрытых разделов.)
3. Какие из новых настроек в таблице нужны? Есть ли то, чего в ней нет?
4. Тема виджетов отдельно от темы приложения — нужна?
5. Открытки: оставить баннер на этой вкладке или увести на главную?
6. Кнопка «Сбросить» (стирает содержимое парного виджета) — оставить в
   шапке или перенести в лист настроек парного виджета?
7. (Проверить до реализации, не к владельцу.) Отдаёт ли iOS список
   поставленных виджетов: в WidgetKit есть
   `WidgetCenter.getCurrentConfigurations`, но мост к нему в приложении
   не проведён, а поддерживает ли его `home_widget` на iOS — не проверено.
   Сейчас экран вызывает `getInstalledWidgets` только для подтверждения
   установки.

# Проверка на двух телефонах

Что прогнать руками после `docker compose up -d` (deploy/README.md) и сборки
APK со своим сервером:

```sh
cp env/example.json env/prod.local.json   # вписать PB_URL своего сервера
flutter build apk --release --dart-define-from-file=env/prod.local.json
```

Или в GitHub: воркфлоу `Fork release APK` (docs/DEVELOPMENT.md, «Сборка в
GitHub»). Артефакт обычного CI (`tethered-arm64-release-debugsigned`) собран
без адреса сервера — для проверки на своём инстансе он не годится.

Сначала `SMOKE_BASE=https://<домен> server/scripts/smoke.sh` — сервер жив,
пара собирается, чат и Centrifugo отвечают.

## 1. Ключи пары (S8)

| Шаг | Ожидание |
|---|---|
| A создаёт приглашение, B открывает **ссылку** | Плашки «Ключи не проверены — сверьте эмодзи» нет: ссылка несёт секрет, пара сверена |
| То же, но B вводит **код руками** | Плашка «ключи не проверены» у обоих |
| Плашка → «Сверить» → эмодзи | У обоих одни и те же 7 эмодзи; «совпадают» у обоих — плашка уходит |
| Вкладка QR в сверке | Скан QR партнёра сверяет без эмодзи |
| Настройки → «Бэкап ключей шифрования» → фраза | 24 слова, без галочки «Я записал(а) фразу» дальше не пускает |
| То же паролем | Слабый пароль (короткий, без цифр, из утечек, с почтой) — подсказки, не принимает |
| Переустановить приложение у A, войти | Экран «Восстановить ключи»; фраза или пароль — история читается снова |
| «Начать заново» вместо восстановления | Предупреждение; после — новая эпоха, партнёр получает ключ, старое не читается |

Замерить: сколько секунд идёт восстановление паролем (Argon2id, 256 МиБ) на
слабом телефоне.

## 2. Данные пары (S9)

Проверка, что сервер видит шифр, — в админке PocketBase (`https://<домен>/_/`)
открыть запись: в полях `e2e1.…`.

| Что | Где смотреть в админке | Ожидание в приложении |
|---|---|---|
| Сообщение, ответ, реакция, правка | `chat_messages.text`, `reactions` | Партнёр видит текст сразу (живая дельта) |
| Поиск по чату «Всё», «Ссылки» | — | Находит по словам из зашифрованных сообщений |
| Уведомление о сообщении, приложение свёрнуто | — | В уведомлении текст, а не «🔒» |
| Воспоминание с фото, подписью, местом | `memories.data.e2e`, файл в `media` | Фото и подпись у партнёра; файл в админке не открывается как картинка |
| Видео в воспоминании, перемотка | — | Играет и перематывается (идёт через локальный прокси) |
| Голосовое и кружок в чате | — | Играют у партнёра |
| Капсула времени на завтра | `memories.data` без `e2e` до срока | Партнёр видит «откроется…», после срока — содержимое |
| Отметка цикла | `cycle_entries.day` = 2000-01-01, `enc` — шифр | Календарь у себя и у партнёра (если поделились) на правильных датах |
| «Где мы» | `live_location.data` | Точка партнёра на карте, движется |
| Настроение, статус, «скучаю» с текстом | `groups.member_moods`, `miss_you.last_vibe_text` | Видны партнёру |
| Желание, рисунок (и живые штрихи вдвоём) | `wishes.title`, `canvas_strokes.data` | Видны партнёру, штрихи рисуются вживую |
| Виджеты на рабочем столе | `widget_data.*` | Фото и статус партнёра в виджете |

## 3. «Смотрим вместе» (§10.1, S11)

| Шаг | Ожидание |
|---|---|
| Оба в комнате из приложения | Чата страницы нет; кнопка чата в углу; строка «зашифрована ключом этого сеанса» |
| Переписка в комнате | Доходит; в канале Centrifugo (логи) — шифр |
| Третий заходит из браузера на компьютере | У приложений строка «в браузере переписка видна серверу»; браузер видит новые реплики |
| `WATCH_PROXY=true`, `WATCH_PROXY_LISTEN=0.0.0.0`, телефон без VPN, где YouTube заблокирован | Ролик YouTube играет в комнате |
| `WATCH_PROXY=false` | `curl --proxy https://<домен>:8443 …` не соединяется |
| Голос в комнате: оба в одном Wi-Fi, потом оба на мобильном интернете | Слышно в обоих случаях (на мобильном обычно через relay) |
| Снаружи: `nmap -p 80,443,3478,8443,49160-49200 <домен>` | Открыты только 443 и 3478 (и 8443 с прокси) |

## 4. «Шифровать всё»

| Шаг | Ожидание |
|---|---|
| Регистрация, имя и аватар | В админке `users.display_name`, `avatar_url` — `e2e1.…`; у себя и у партнёра — настоящие |
| Партнёр открывает ваш профиль | Имя, аватар, баннер, день рождения — из записи пары (`groups.member_cards` шифром) |
| A без ключей (новый телефон, бэкап не восстановлен) пишет в чат | Сразу видно, что не ушло и почему («нужно восстановить ключи»); в админке сообщения нет. Касание по закрытому сообщению — лист с причиной и кнопкой «Восстановить ключи» |
| Подарок с запиской, «Песня», ответ на звезду, подарок из сундука | `gifts.note`, `place`, `sound_meta`, `reply` — шифр; у партнёра открыто |
| Пара с пустым местом | `groups.placeholder_name` — шифр (сначала «…»), у себя имя видно |
| Наклейка на воспоминание | Видна у обоих; в `memories.data` наклейки нет открытой |
| Свой ролик в «Смотрим вместе» | Играет в приложении, перематывается; файл в админке не открывается |
| Браузер заходит в комнату | Приложение пишет «в комнате браузер», реплики браузера скрыты; после «Разрешить» — открытый чат с пометкой |
| Голос в комнате | Соединяется; в логах Centrifugo нет `voice-offer` открытым |
| В админке `_logs` | Пусто: журнал запросов выключен |
| Регистрация и смена пароля с `Parol_123`, `P@ssw0rd2024!`, паролем с почтой | Не принимает, подсказки те же, что у пароля бэкапа |

## 5. Пуши-будильник FCM (S12)

Сборка с `GOOGLE_SERVICES_JSON`, на сервере `FCM_CREDENTIALS_FILE`
(deploy/README.md, «Пуши»).

| Шаг | Ожидание |
|---|---|
| Вход на телефоне с сервисами Google | В шторке нет строки «на связи»: фоновый сокет не поднялся |
| B смахнул приложение из недавних, экран погас; A пишет в чат | У B уведомление с текстом сообщения за секунды |
| То же со «скучаю», подарком, новым воспоминанием, зовом в ленту | Уведомления те же, что раньше от сокета |
| B с открытым чатом | Второго уведомления нет |
| `docker compose logs server`, трафик сервера к `fcm.googleapis.com` | В теле только `type` и `event`; id пары и текста нет |
| Сервер без `FCM_CREDENTIALS_FILE` | Телефон держит фоновый сокет, как раньше |
| B вышел из аккаунта | Пуши этому телефону больше не приходят |

## 7. UX: состояние и ошибки видны (docs/history/UX_AUDIT.md)

| Шаг | Ожидание |
|---|---|
| A звонит из шапки чата | Плашка «Зовём…» → «Соединяем…» → таймер; у B карточка входящего на любом экране |
| B смахнул приложение из недавних; A звонит | У B «Входящий звонок — Партнёр звонит»; тап открывает приложение, карточка входящего появляется, пока A зовёт (45 с) |
| Связь посреди разговора пропала | «Восстанавливаем…», потом либо разговор, либо «Не вышло» с причиной и «Повторить» |
| B входит в комнату/ленту и выходит | У A в чате комнаты «Партнёр зашёл» / «Партнёр вышел» |
| Комната на телефоне 412 точек | У трубки подпись «Звонок»; в разговоре кнопки микрофона и отбоя крупные, кнопка темы спрятана |
| A открывает свой ролик в «Смотрим» | У B на экране «Смотрим» плашка «Партнёр смотрит «…» — Открыть» |
| Ролик из галереи | «Загружаю N МБ…» с отменой; сбой — с причиной |
| A зовёт порисовать, приложение B закрыто | Уведомление; тап открывает рисунки, а не главную |
| «Сверить ключи»: нажмите «Начать» оба одновременно | Сверка одна, эмодзи одинаковые |
| «Сверить ключи»: B не отвечает | Через 2 минуты у A «Телефон партнёра не ответил» и «Начать заново» |
| Сверка: B нажимает «Не сейчас» | У A «Партнёр отменил сверку», а не «эмодзи не совпали» |
| Отключиться от пары без сети | «Не получилось отключиться… пара осталась как была», пара на месте |
| Сменить пароль на одном телефоне | Второй при следующем запуске на экране входа объясняет: вход отозвал сервер, пара и переписка на месте |
| Удалить аккаунт | Текст: неделя ожидания, пара у партнёра жива, вход отменяет удаление |
| Выключить отправку геопозиции | У партнёра точка пропадает сразу, а не висит последней |
| Комната/лента: одно «назад» кнопкой или жестом | Выходит сразу, без «нажмите ещё раз» |
| Во время звонка коснуться плашки | Звонок на весь экран: имя, состояние, микрофон, звук, отбой; стрелка вниз сворачивает обратно в плашку |
| Партнёр не ответил | У плашки крестик — закрывается без нового звонка; «Позвонить ещё» — отдельно |
| Включить показ геопозиции, дать «При использовании» | Подсказка «Разрешить» открывает страницу разрешения, где есть «Разрешать всегда» |

## 11. Замок приложения (план 3.1)

- На Android в «Телефон и экран блокировки» включить «Замок приложения»: система просит отпечаток или PIN/пароль устройства. Отмена оставляет переключатель выключенным. На телефоне без PIN — понятная подсказка и переход к настройкам защиты.
- Перезапустить процесс: содержимое пары и диалоги закрыты до проверки. Отмена/ошибка не открывают экран; успешная проверка возвращает прежний маршрут.
- Уйти на домашний экран и вернуться, выключить/включить экран: нужна новая проверка. Проверить также возврат из системного PIN-диалога на Android 8–9. Шторка поверх приложения временно закрывает содержимое.
- С открытым секретным экраном и обычным диалогом открыть «Недавние»: содержимое скрыто. Проверить Android 13+ и старую версию отдельно. На Android <13 используется FLAG_SECURE: он также запрещает скриншоты во всё время включённого замка.
- «Блокировать после фона»: Сразу / 1 мин / 10 мин / 1 час. С 10 минутами выбрать фото из галереи или сходить в другое приложение на пару минут — вход без проверки; через 10+ минут — проверка. «Недавние» скрыты в любом случае. Удлинение срока просит проверку, сокращение — нет. Перезапуск процесса блокирует всегда. На Android 8–9 после системного PIN-диалога замок не должен закрываться повторно.
- Отключение требует проверки устройства; отмена сохраняет замок. После отключения секретные маршруты по-прежнему запрещают скриншоты своей защитой.
- С включённым замком открыть уведомление и ссылку приглашения из фона: содержимое не показывается до проверки. Проверить TalkBack, тёмную тему, ru/en и крупный шрифт.

## 12. Прикосновение (план 3.2)

- На двух телефонах пары открыть «Скучаю» → иконку прикосновения. Удерживать пальцы на разных участках, затем совместить точки: оба телефона вибрируют один раз при совпадении, удержание не вызывает повторов. Перемещение не прокручивает страницу.
- Отпустить палец, свернуть приложение, выключить экран, отключить сеть: старая точка исчезает, вибрация прекращается. После восстановления связи удерживаемый палец снова передаётся; координаты не остаются в истории.
- «Позвать партнёра» показывает успех после ответа сервера; при отказе — причину/повтор. На втором телефоне приходит уведомление с переходом прямо к прикосновению, в том числе с закрытого приложения и через замок. Повторные частые приглашения ограничены сервером; пуш старше двух минут не показывается.
- Сменить ключи/выйти из пары/аккаунта: прикосновение недоступно, отправки открытым текстом нет. Проверить ru/en, тёмную тему и крупный шрифт.

## 13. Плитки шторки Android (план 3.3)

- До включения настройки «Плитки в шторке» в редакторе шторки нет новых плиток Tethered. Включить настройку, открыть редактор «Изменить» и добавить «Скучаю»/«Прикосновение».
- Каждая плитка открывает соответствующий экран, включая закрытое приложение и ещё загружающуюся пару. «Скучаю» открывает счётчик без автоматической отправки сообщения. При включённом замке экран закрыт до проверки.
- Нажать плитку с заблокированного телефона: Android сначала просит разблокировку. Проверить Android 13 и 14+ отдельно (разные API запуска).
- Отключить настройку: новые плитки исчезают из доступных; уже добавленные становятся недоступны, их можно удалить в редакторе шторки. После перезапуска/обновления приложения выбранное состояние сохраняется.
- Проверить ru/en подписей плиток, отсутствие строки настройки на iOS/Android ниже 7, возврат из ошибок проверки/переключения без ложного состояния «включено».

## 14. Совпадения роликов (план 3.4)

- В ленте приложения отреагировать одинаково на одном ролике с двух телефонов. После выхода открыть «Совпадения в ленте» на вкладке совместного просмотра: ролик доступен обоим. Повторить реакции и одновременный матч — дубликат не появляется.
- Перезапустить приложение, открыть сохранённый ролик, проверить платформу/реакцию/дату. Удаление требует подтверждения и удаляет общую запись; при недоступном сервере запись не исчезает и показана ошибка.
- На телефоне без прежних ключей вместо пустого списка виден закрытый ролик. Восстановить ключи — содержимое читается. После смены ключа повторно совпавший доступный ролик не дублируется.
- Отключить сеть при совпадении: нет ложного «сохранено», есть ошибка и повтор. Открыть список без сети — ошибка отличается от пустой коллекции. Проверить 320dp/200% текста.
- В браузере без приложения ключей пары нет: анимация совпадения остаётся, сохранение просит открыть приложение. PB-токен в страницу не передаётся.

## 15. Очередь комнаты (план 3.5)

- В приложении открыть комнату → действия с видео → «Очередь видео» (в пустой комнате есть отдельная кнопка). Добавить ссылки через тот же выбор видео. Второй участник видит тот же список и текущий ролик; оба могут добавить, убрать или включить конкретный пункт.
- На двух телефонах одновременно добавить разные ссылки, удалить пункт, переподключиться/войти третьим окном браузера: порядок совпадает, удалённое не возвращается. Общая очередь сохраняется, пока хотя бы один участник держит комнату открытой; после ухода всех исчезает.
- Включить первый пункт и дождаться конца HTML-video/YouTube/VK/Vimeo/Rutube: следующий запускается у обоих один раз. У Drive/MEGA и других плееров без сигнала конца — явная кнопка «Следующее». Блокировку автозапуска площадкой проверять на телефоне; при необходимости человек жмёт Play.
- Без связи операции не притворяются успешными. Лимит 20, неправильная ссылка и локальный файл без общего адреса объясняются. Проверить 320dp/200% текста, текущий ролик, удаление и управление браузерным диалогом.

## 16. Android PiP (план 3.6)

- На Android 8+ открыть видео в комнате → действия с видео → «Поверх приложений (PiP)». В маленьком окне только видео: без чата, имён, звонковых плашек, ошибок очереди/синхронизации. Видео не перезагружается при входе/выходе и продолжает играть; проверить прямой файл и iframe площадки.
- Перейти в другое приложение, раскрыть маленькое окно: возвращается прежняя комната/чат и позиция видео. Нажать системный крестик PiP: собственная комната закрывается; расширение PiP не должно трактоваться как её закрытие.
- Запретить PiP для Tethered в системных настройках: не показывается ложный маленький режим, есть понятная причина и переход к настройкам. На неподдерживаемом устройстве — сообщение об этом.
- Включить замок приложения: PiP не включается, замок продолжает закрывать приложение после фона. Если другой маршрут/уведомление перекрыл комнату во время перехода, чужое содержимое не попадает в маленькое окно; при потере владельца оно остаётся чёрным до выхода из системного PiP.
- Во время PiP вызвать входящий звонок, обрыв связи, отказ видео: глобальные Flutter-плашки не перекрывают кадр. Проверить Android 8–11 и 12+, поворот и возвращение из шторки.

## 17. «Что посмотрим?» (план 3.7)

- У пары на вкладке совместного просмотра открыть «Что посмотрим?». Во вкладке «Добавить» найти фильм/сериал через поиск своего сервера и добавить в общую колоду. На другом телефоне карточка появляется без повторного поиска; без пары вход отключён.
- Вправо — «Хочу смотреть», влево — «Не сейчас»; те же решения доступны кнопками. Карточка переходит дальше после подтверждения записи. При отказе/нет ключей она остаётся, показана причина и повтор. Последний выбор отменяется, возвращая карточку.
- Два независимых «да» дают совпадение и общий список; «нет» одного участника не становится совпадением. Проверить ru/en названия одного фильма: идентификатор провайдера снимает дубликаты. Повторное добавление не сбрасывает прошлую оценку.
- Оценки/метаданные сохраняются после перезапуска. Смена ключа не дублирует читаемую собственную запись. Нет старых ключей — закрытые карточки явно отмечены; данные не пересылаются открытым текстом.
- Проверить поиск с клавиатурой на 320dp/200%, прокрутку вкладок, длинное описание, сломанный постер, ссылки на сведения о фильме. Отказ поиска отличается от отсутствия результатов. Старый GET во время успешного свайпа не возвращает уже оценённую карточку.

## 18. Хвост аудита: выход, FCM, карта и realtime

- При включённой геопозиции выйти из аккаунта: системный индикатор и поток
  прекращаются, последняя точка не дописывается после выхода. Войти другим
  аккаунтом: старые таймеры заряда и присутствия не возобновляются.
- На телефоне с настроенным FCM сменить аккаунт: старый токен не переносится,
  native FCM выдаёт новый. При отказе/отсутствии FCM остаётся фоновый сокет.
  Проверить уведомление после закрытия приложения.
- Открыть карту со старым кэшем и после очистки: TileJSON/PBF идут только
  через свой сервер, атрибуция OpenStreetMap остаётся видна.
- Перед обновлением realtime выполнить ротацию TOKEN_HMAC и рестарт брокера
  из deploy/README.md. После расставания refresh подписки запрещён; новая
  подписка может читать до своего истечения (120 с плюс grace брокера).
- Включить авиарежим и вернуть сеть: серверные дельты снова приходят после
  получения HTTPS-ключа. Проверить телефон с вручную сбитыми часами: срок
  конверта берётся с сервера и монотонного таймера.

Автоматически проверены запрет записи от чужого автора, подмена uid,
очистка переговоров/отозванных выдач, границы Argon2, headless logout,
перехват FCM, старый внешний кэш карты, подпись/повторы/каналы дельт и
настоящие Centrifugo/JS-маршруты. Биометрия, плитки, PiP и доставка FCM
требуют отдельной проверки на физическом Android (разделы 11–17).

## 20. «Хочу с тобой» (вишлист, docs/WISHLIST.md)

На двух телефонах пары, шифрование включено.

- **Когда.** Новое желание → «Дата»/«Месяц»/«Когда-нибудь»: на карточке
  срок, просроченное красным; желание с датой видно в «Нашем календаре» (✨).
- **Я тоже хочу.** На желании партнёра — сердечко: у обоих карточка в
  обводке и «Хотим оба».
- **Сбылось чужое.** Отметить галочкой желание партнёра → у обоих оно в
  «Сбылось», без ошибки синхронизации.
- **Порядок.** Долгое нажатие в «Мечтаем» и перетащить → у партнёра тот же

- **Комментарии.** Меню карточки → «Комментировать» → у партнёра счётчик на
  карточке; своё удаляется долгим нажатием, чужое — нет.
- **Напоминания.** Колокольчик → «Напоминания»: добавить отметку «за 1 час»,
  поставить желанию дату на сегодня через пару часов — уведомление приходит;
  «Желание недели» на ближайшую минуту — приходит с названием; «Другое» на

- **Подсказки к датам.** Поставить партнёру день рождения через 14 дней,
  у партнёра в вишлисте вещь → утром подсказка только вам. Взять вещь
  «Дарю» → подсказка больше не ставится.
- **Срок «Дарю».** «Дарю» → «СРОК» → завтра: накануне и в день —
  уведомление; после срока значок подарка красный.
- **Место.** Желание «Место» → «Место на карте» → метка. Оба включают «Где
  мы» и идут к месту (радиус в настройках) → обоим «Вы оба рядом»; второй

- **Сбылось и воспоминание.** В «Сбылось» → «Привязать воспоминание» →
  выбрать → «Воспоминание» открывает ленту на нём. «Стена» — плитки и
  счётчики.
- **Поделиться.** Из Яндекс Карт / Google Maps «Поделиться → Tethered» →
  форма «Места» с меткой и названием; из магазина — как раньше, вещь.

## 21. Сервер на Go вместо JS-хуков (этап 2, 25.10)

Пара на двух телефонах, сервер со свежим образом.

- **Отложенное сообщение.** Долгое нажатие на «отправить» → через 3 минуты.
  У автора — пометка «придёт в …», у партнёра в чате пусто и уведомления
  нет. Через 3 минуты (до 15 секунд сверху) сообщение приходит партнёру с
  уведомлением и встаёт в переписку временем срока. «Отправить сейчас» —
  приходит сразу.
- **Серия.** Оба заходят в один вечер → огонёк +1; пара из разных поясов
  (один после полуночи) тоже засчитывается. Пропустить два дня, зайти →
  счётчик серии может начаться заново, но питомец не грустит, не уменьшается
  и не предлагает восстановление за рекламу.
- **Почта.** Вход с «Anna@…» при аккаунте «anna@…» пускает; «Забыли
  пароль» с заглавной — письмо приходит. Смена почты кодом в профиле.
- **Пара в ожидании.** «Он в армии» → код второго места → второй телефон
  вводит код → хозяйка подтверждает → у обоих одна пара с историей.
- **Ссылка-приглашение.** Открыть `https://<домен>/invite/<код>` на телефоне
  с приложением → приложение открывается с кодом; без приложения — страница
  с кодом и кнопками магазинов из `.env`.
- **Живое фото в виджете.** Видео в виджет пары → у партнёра виджет
  шевелится (раскадровка с сервера).
- **Зовы.** Открыть раскраску → партнёру «зовёт порисовать» (не чаще раза в
  полчаса); лента вдвоём → «зовёт смотреть …».

## 22. Наш дом и спокойная забота (26.10)

Автоматически проверено: модель покупок и постоянных наград; 112 пар реплик
RU/EN без повторов до исчерпания набора; шифрование и AAD связи; повтор
после потерянного ответа; покупка при конфликте версий; реальная транзакция
двух участников; запрет чужой связи, прямой записи коллекции и записи после
выхода; сохранение роста после сброса серии; отмена старого уведомления без
запроса разрешений. Виджетные тесты: уход, покупка и размещение, обращения,
320 dp с увеличением текста ×2 и клавиатурой, согласование после возвращения
из фона. Реальный рендер: [скриншот](images/pet-home.webp).

На двух физических телефонах проверить:

1. Главная → питомец → «Наш дом». Галерея доступна из верхней кнопки:
   нарисовать своё, загрузить PNG с альфой, обычный JPEG, выбрать старого
   пиксельного питомца — всё видно в комнате; рисунок не перерисовывается.
2. Угостить любым угощением, помыть, поиграть, погладить: короткая реакция,
   облачко с репликой/эмоутом исчезает. Можно делать сколько хочется, без
   расхода валюты и без обязательного интервала. У второго — новое состояние.
3. Оба одновременно покупают разные предметы при достаточном общем балансе:
   обе покупки сохраняются. При нехватке на обе — одна проходит, вторая
   показывает нехватку очков; баланс не становится отрицательным. Купленный
   предмет убрать и вернуть бесплатно; замена сохраняется у обоих.
4. Выбрать собственное обращение «мама», «папа», ник. Два одинаковых обращения
   разрешены. Для дружеской связи — имена/прозвища; роли по полу не выбираются.
5. Закрыть на несколько дней: нет напоминаний о питомце, потери мебели,
   очков или роста. Старое запланированное уведомление 9991 отменяется при
   первом старте обновлённой версии. Серия — отдельный необязательный счётчик.
6. Фоновый режим/обрыв сети/возвращение: актуальная обстановка загружается;
   без ключа связи запись блокируется. Повтор покупки не списывает дважды.
   Сменить аккаунт или активную связь при открытом доме: старый экран не пишет.
7. TalkBack: названия пяти действий, кнопок галереи/настроек, объявление
   реплики. Системное уменьшение движения: нет подпрыгиваний/покачиваний.
   Текст ×2, клавиатура, портрет/альбом: действия и сохранение доступны.
8. Домашний виджет со взрослым питомцем после перерыва: сохраняется взрослый
   кадр и заполненная полоса роста, питомец не показывает грустную сцену.

Проверки на физических Android/iOS в этой среде не выполнялись.

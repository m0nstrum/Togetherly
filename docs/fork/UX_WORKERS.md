## Правила

1. **Сначала проверь находку по коду.** Аудит сделан чтением, без запуска; в нём
   бывают ошибки. Не подтвердилась — в таблице статус **отклонено** с причиной.
2. **Минимальная правка.** Не переписывай экраны и не меняй то, что не просили.
3. **Файлы апстрима** (всё вне `lib/fork`, `test/fork`, `server`, `deploy`,
   `docs/fork`, `tool/fork`):
   - никогда не запускай `dart format` на них — правь точечно;
   - каждую правку помечай комментарием `// fork:` (в HTML — `<!-- fork: … -->`);
   - каждый тронутый файл — строка в [TOUCHPOINTS.md](TOUCHPOINTS.md) (полный
     путь в первой колонке в обратных кавычках, без других обратных кавычек в
     первой колонке).
   - Больше 20–30 строк нового кода — выноси в файл `lib/fork/...` и зови оттуда.
4. **Обратная связь — через `lib/fork/ui/feedback.dart`:** `ForkFailure.of(e)`,
   `Outcome.guard`, `ForkNotice.failure/error/info`, `ForkStatusBar`. Тексты —
   `ruEn('по-русски', 'in English')` из `lib/dict_strings.dart`.
5. **Платного в форке нет** (`ForkFlags.allFree`): Плюс открыт, рекламы нет,
   денег нет. Монеты — игровая механика без денег, их не трогаем.
6. **Тесты.** На каждую правку логики — тест в `test/fork/...` (или правка
   существующего). Тексты в тестах апстрима проверяются с
   `--dart-define-from-file=env/test.json`.

## Проверки перед пушем

```sh
export PATH=/opt/flutter-sdk/flutter/bin:$PATH
tool/fork/analyze_check.sh                      # базовая линия 37 предупреждений

```

Все три — зелёные, иначе не пушим.

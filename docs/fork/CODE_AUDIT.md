# Аудит кода (23.10.2026)

Прочитано по коду:

- сервер на Go (`server/internal`): правила доступа, стражи, роуты форка, удаление аккаунта;
- JS-хуки апстрима в `server/pb_hooks`;
- деплой: Caddy и Centrifugo;
- клиентский E2E (`lib/fork/e2e`), выход из аккаунта, офлайн-очередь, хранилища ключей;

Каждая находка проверена по коду. Пометка «проверить» означает, что вывод сделан по коду и на телефоне не подтверждён.

Аудит интерфейса — отдельно, в `UX_AUDIT.md` (раздел «Аудит интерфейса 23.10»).

## Проверено, проблем нет

- Скрытое `group_ids`: PocketBase вырезает скрытые поля из тела запроса, вписать себе чужую пару нельзя.
- Экономические поля `users`: страж `users_guard`.
- Состав группы: страж `groups_guard`, добавлять участников через API нельзя.
- Защита от SSRF (`safefetch`): проверка IP при соединении, только порты 80 и 443.
- Внутренний API (`compat`) отвечает только на петле.
- Медиапрокси: секрет в пути, слушает только петлю.
- Крашрепорты: только с согласия, без PII.
- Комментарии TikTok выводятся через `textContent`.
- Конверт E2E: AAD привязан к месту; XChaCha20-Poly1305.

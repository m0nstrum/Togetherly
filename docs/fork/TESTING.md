# Проверка на двух телефонах

Что прогнать руками после `docker compose up -d` (deploy/README.md) и сборки
APK со своим сервером:

```sh
cp env/example.json env/prod.local.json   # вписать PB_URL своего сервера
flutter build apk --release --dart-define-from-file=env/prod.local.json
```

Или в GitHub: воркфлоу `Fork release APK` (docs/fork/README.md, «Сборка в
GitHub»). Артефакт обычного CI (`tethered-arm64-release-debugsigned`) собран
без адреса сервера — для проверки на своём инстансе он не годится.

Сначала `SMOKE_BASE=https://<домен> server/scripts/smoke.sh` — сервер жив,
пара собирается, чат и Centrifugo отвечают.

## 1. Ключи пары (S8)

| Шаг | Ожидание |
|---|---|
| A создаёт приглашение, B открывает **ссылку** | Плашки «Ключи не проверены — сверьте эмодзи» нет: ссылка несёт секрет, пара сверена |
| То же, но B вводит **код руками** | Плашка «ключи не проверены» у обоих |
| Плашка → «Сверить» → эмодзи | У обоих одни и те же 7 эмодзи; «совпадают» у обоих — плашка уходит |
| Вкладка QR в сверке | Скан QR партнёра сверяет без эмодзи |
| Настройки → «Бэкап ключей шифрования» → фраза | 24 слова, без галочки «Я записал(а) фразу» дальше не пускает |
| То же паролем | Слабый пароль (короткий, без цифр, из утечек, с почтой) — подсказки, не принимает |
| Переустановить приложение у A, войти | Экран «Восстановить ключи»; фраза или пароль — история читается снова |
| «Начать заново» вместо восстановления | Предупреждение; после — новая эпоха, партнёр получает ключ, старое не читается |

Замерить: сколько секунд идёт восстановление паролем (Argon2id, 256 МиБ) на
слабом телефоне.

## 2. Данные пары (S9)

Проверка, что сервер видит шифр, — в админке PocketBase (`https://<домен>/_/`)
открыть запись: в полях `e2e1.…`.

| Что | Где смотреть в админке | Ожидание в приложении |
|---|---|---|
| Сообщение, ответ, реакция, правка | `chat_messages.text`, `reactions` | Партнёр видит текст сразу (живая дельта) |
| Поиск по чату «Всё», «Ссылки» | — | Находит по словам из зашифрованных сообщений |
| Уведомление о сообщении, приложение свёрнуто | — | В уведомлении текст, а не «🔒» |
| Воспоминание с фото, подписью, местом | `memories.data.e2e`, файл в `media` | Фото и подпись у партнёра; файл в админке не открывается как картинка |
| Видео в воспоминании, перемотка | — | Играет и перематывается (идёт через локальный прокси) |
| Голосовое и кружок в чате | — | Играют у партнёра |
| Капсула времени на завтра | `memories.data` без `e2e` до срока | Партнёр видит «откроется…», после срока — содержимое |
| Отметка цикла | `cycle_entries.day` = 2000-01-01, `enc` — шифр | Календарь у себя и у партнёра (если поделились) на правильных датах |
| «Где мы» | `live_location.data` | Точка партнёра на карте, движется |
| Настроение, статус, «скучаю» с текстом | `groups.member_moods`, `miss_you.last_vibe_text` | Видны партнёру |
| Желание, рисунок (и живые штрихи вдвоём) | `wishes.title`, `canvas_strokes.data` | Видны партнёру, штрихи рисуются вживую |
| Виджеты на рабочем столе | `widget_data.*` | Фото и статус партнёра в виджете |

## 3. «Смотрим вместе» (§10.1, S11)

| Шаг | Ожидание |
|---|---|
| Оба в комнате из приложения | Чата страницы нет; кнопка чата в углу; строка «зашифрована ключом этого сеанса» |
| Переписка в комнате | Доходит; в канале Centrifugo (логи) — шифр |
| Третий заходит из браузера на компьютере | У приложений строка «в браузере переписка видна серверу»; браузер видит новые реплики |
| `WATCH_PROXY=true`, телефон без VPN, где YouTube заблокирован | Ролик YouTube играет в комнате |
| `WATCH_PROXY=false` | `curl --proxy https://<домен>:8443 …` не соединяется |

## Что прислать, если не работает

Логи приложения (`adb logcat | grep -E "ForkE2E|MediaProxy|ForkWatchProxy"`),
журнал сервера (`docker compose logs server`) и шаг из таблицы.

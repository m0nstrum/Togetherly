## Баги

| # | Что | Статус | Заметки |
|---|---|---|---|
| B1 | Тап по уведомлению «зовут в комнату» ничего не открывает | ✅ | Плагин уведомлений хранит один колбэк нажатий — от последнего `initialize`. Шесть сервисов апстрима вызывали его без колбэка и затирали наш. Теперь все передают `ForkNotifTap.onResponse`. |
| B2 | Тап по «партнёр зовёт порисовать» ничего не делает | ✅ | Та же причина, что B1. |
| B3 | В TikTok-ленте по-прежнему «гость» | ✅ | Синхронизация профиля затирала имя шифром или пустотой, пока ключ не открылся. Теперь берётся только годное имя; реплика без подписи — именем партнёра. Проверить на телефонах. |
| B4 | Зашёл в комнату сам — «ничего не выбрано», хотя партнёр уже выбрал ролик | ✅ | Пустая вкладка отвечает на hello встречным (echo), новичок повторяет hello, очередь тоже снимок (`room/fork-sync.js`). Проверено в Chromium-стенде; на телефонах — проверить. |
| B5 | Пауза плеера YouTube не синхронизируется с кнопкой паузы интерфейса | ✅ | `actSync` до `noteAct` глушил отчёт о нажатии в кадре. Проверено в Chromium с заглушкой YT. |
| B6 | Видео из TikTok, добавленное в воспоминания, потом не грузится | ✅ | Подписанная обложка CDN истекала и не проходила шлюз — не храним и не показываем; ссылка с ником автора. Проверить на телефоне, что ролик открывается. |
| B7 | Виджеты обрезаются снизу: «Скучаю» 2×2 на OnePlus 9R теряет кнопку; остальные проверить | ⏳ | Фиксированные блоки `tg_miss_2x2.xml` в сумме ≈148dp, а 2×2 гарантирует 110dp (`minHeight`); растяжка между ними только растёт. Чинить: провайдер читает `OPTION_APPWIDGET_MIN_HEIGHT` и в тесноте прячет «Сегодня», уменьшает число и кнопку (как `NoteWidgetProvider`); тест-страж — сумма фиксированных высот каждого `tg_*` против `minHeight` его `*_info.xml`. |
| B8 | Время комментариев к воспоминаниям — по Гринвичу | ⏳ | Клиент шлёт UTC и пояс в `tz`, но в `memory_comments` нет поля `tz` — PocketBase его отбрасывает, и `PairTime.read` читает запись как старую. Чинить: миграция с текстовым `tz`; уже написанные останутся сдвинутыми. |
| B9 | Статистика пары показывает шифр вместо значений | ⏳ | Сервер (`usecase/stats`) группирует зашифрованные поля: имена участников (`users.display_name`) и разбивку просмотров (`watch_history.kind` — у каждой записи свой шифр). Чинить на клиенте рядом с `patchCoupleStats`/`_patchMoods`: имена из `groups.member_names`, разбивку — из расшифрованной истории. Плюс страж: каждое поле ответа либо открытое, либо подменяется клиентом. |
| B10 | Синхронизация онлайна: партнёр «не в комнате», хотя пишет и жмёт кнопки; «неткод плохой» | ⏳ | Присутствие не разобрано. Общая плохая синхронизация, вероятно, — RT-1 и RT-2 из аудита 29.10 (ниже). |
| B11 | Прикосновение: «нет связи» при живом соединении | ⏳ | Не разобрано; вероятно, одна причина с B10 — признак связи берётся не из реального состояния сокета. |
